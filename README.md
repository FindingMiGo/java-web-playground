# java-web-playground

Java Servlet/JSP の練習用リポジトリ。

## 構成

| モジュール | 内容 |
|---|---|
| `customer-tracker` | 得意先CRUD + 受注一覧（Servlet, JSP, JDBC, JUnit） |
| `talent-registry` | タレント管理（Servlet, DAO, JSP） |
| `core` | 共通基盤（BaseDao, 例外クラス） |

## 技術要素
Maven マルチモジュール / Servlet / JSP / JDBC / JUnit / Docker / GitHub Actions
